KEY LESSONS (violated each of these at least once before)
================================================================================
- Calibrate penalty weights by MEASURED WEIGHTED CONTRIBUTION against a real
  checkpoint (zero-others method), never by "did the count drop" — a swamping
  term always looks like it's working (DECISION_LOG.md 2026-07-12/13).
- A soft penalty can sit below the selection noise floor against the benefit
  it fights (~1000:1 measured for unsupported duplicates). If so, add a
  targeted repair operator — repair beats weight escalation for structurally
  fixable constraints (this repo's proven pattern: same_layer_duplicate,
  momentary_key_reuse, unsupported_duplicate).
- Archive admission is acceptance-gated; a steadily-improving population best
  that fails acceptance leaves the archive frozen for tens of thousands of
  gens. Check BOTH archive and population trends before calling stagnation.
- Validate external genomes at load (stale data snapshots crash CUDA
  embeddings with out-of-range sids).
- Run `just ai-guard` only on an IDLE GPU — an active run contends and reads
  falsely ~20% slow. Never update the perf baseline for contention noise.
